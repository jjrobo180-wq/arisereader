# Arise Undercover (iPhone)

The AI chat that looks like texting or a document (client/src/undercover/UndercoverApp.tsx), built from the shared
frontend with `VITE_NATIVE_APP=undercover` by `.github/workflows/undercover-ios.yml`. A push to
`feat/undercover-testflight` with `[approved-testflight]` in the commit message uploads a build to TestFlight.
No live updates yet: each change ships as a new build.
First build: 2026-11-11.
