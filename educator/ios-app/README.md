# A.R.I.S.E. Reader Educator (iPhone)

The teacher and parent A.R.I.S.E. Reader app. Bundle ID `com.arisereader.educator`
(App Store Connect app 6829105128). Built from the shared frontend with `VITE_NATIVE_APP=educator`
by `.github/workflows/educator-ios.yml`, which uploads to TestFlight for a pushed commit on
`feat/educator-testflight` whose message has `[approved-testflight]`.
