ARISE READ ALOUD  (Chrome / Chromebook)

Reads what is on the screen out loud in a natural AI voice and highlights each part as it is read.

INSTALL (one computer, to try it)
1. Unzip this folder.
2. In Chrome go to chrome://extensions
3. Turn on "Developer mode" (top right).
4. Click "Load unpacked" and choose the arise-read-aloud folder.
5. Open the Pear Deck lesson. A purple speaker button appears at the bottom right.
   (On any other website, click the extension's icon in the toolbar to show the button.)

USE
- Tap the speaker, then "Read this screen". It reads what is visible, top to bottom.
- Select some words first to hear only those.
- Pause, Stop, speed and voice are in the panel. Keyboard: Alt+Shift+R reads / pauses / resumes.

FOR A CLASS OF CHROMEBOOKS
Your school IT admin can force-install it for students in the Google Admin console
(Devices > Chrome > Apps & extensions) by uploading the extension. Developer mode is not needed that way.

PRIVACY
The text on the screen is sent to arisetodo.com only to turn it into speech. No names, accounts or answers are sent.
If the AI voice cannot be reached, it falls back to the device's own voice.
